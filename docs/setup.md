# Model setup

Use the implementation and [setup guide on `harrison/mosp-reproduction`](https://github.com/chefOST/mosp/blob/harrison/mosp-reproduction/docs/setup.md).
This branch contains no model runtime.

[Shared data](https://github.com/chefOST/chefOST-data) supplies annotations and
vocabularies. A real training/validation split and complete feature collection
have not yet been prepared. The implementation's setup guide records the
available inputs and CLI requirements.

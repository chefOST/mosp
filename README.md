# MOSP / ChefOST

This branch contains an earlier MOSCATO-inspired model in the `moscato` package:
a Transformer state predictor with action-label cross-attention. It does not
implement the paper's MS-TCN++/SAI architecture.

Current model work and setup are on
[`harrison/mosp-reproduction`](https://github.com/chefOST/mosp/tree/harrison/mosp-reproduction),
using the `mosp` package. No real training or benchmark result has been established.

Paper: [MOSCATO: Predicting Multiple Object State Change through Actions](https://www.khoury.northeastern.edu/home/eelhami/publications/iccv25_moscato.pdf).

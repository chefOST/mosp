# Project guidance

- Read README.md, then the linked documentation and paper notes relevant to the task.
- Keep documentation concise; link canonical context instead of duplicating it.
- Distinguish published results, ChefOST experiments and proposals.
- This repository contains model training and prediction only. Keep scoring, benchmark metrics, ground-truth evaluation and validation-based checkpoint selection outside this repository. Training losses, input checks and held-out-ID exclusion checks belong here.
- Keep datasets, features, checkpoints, credentials and generated runs out of Git.
- Newer user instructions and supplied announcements take precedence over older notes.
